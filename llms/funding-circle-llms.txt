# Funding Circle

> Funding Circle is a UK small-business lending marketplace offering term business loans, FlexiPay lines of credit, a cashback business credit card, government-backed Growth Guarantee Scheme loans, and asset finance. Its Introducer API lets partners and brokers submit and manage loan applications programmatically using OAuth 2.0 client credentials, RFC 7807 error semantics, a sandbox with documented test values, and callback-URL webhooks.

## API
- [Introducer API reference](https://www.fundingcircle.com/uk/partners/developer/api-doc/): term and FlexiPay loan application submission, status polling, credit decisions, and document upload.
